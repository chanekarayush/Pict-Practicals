# Assignment Writer Skill for Claude 

Add this skill to your claude code enviroment or [Claude AI](claude.ai) workspace

## Usage
If you have a lab manual for your respective subject upload it to claude or add that as an input in your claude code.
OR 
Just provide the title and problem statement

Claude will generate a docx file for the assignment.
Please ensure you have the [docx skill for claude](https://github.com/anthropics/skills/tree/main/skills/docx) (Install it from here if you want)

Remember... Don't Hate the Players Hate the Game.
